# Stage 00 Plan: Project Control System

## Purpose

Create the governance and operating system for FinSignalHub before any business code is written.

## Scope

Allowed: control files, capability audit, logs, stage roadmap, local skills, local plugin draft, GitHub/GPT Pro protocols, review packets, workflows, and acceptance materials.

Forbidden: FastAPI, database, MCP tool implementation, connectors, frontend, dashboards, report generation, stock recommendation, investment advice, or generic RAG behavior.

## Skills

Use `codex-log-keeper`, `phase-gate-auditor`, `finsignal-product-governor`, `gpt-pro-review-preparer`, `github-stage-deployer`, and `browser-gpt-pro-reviewer` as local Stage 00 governance skills after creation.

## Tests

Run file existence, heading, skill section, plugin manifest, workflow, GitHub auth, and capability checks only.

## GitHub

Target branch is `stage/00-control-system`. Because this workspace is not a Git repository and `gh` is not authenticated, Stage 00 must create manual deployment steps and blockers unless the user provides a repository and GitHub authentication.

## GPT Pro

Generate a copy-ready Stage 00 review packet. GPT Pro browser submission requires user-approved Chrome extension interaction. If access is blocked, record a blocker and do not mark Stage 00 complete.

## Done-When

Stage 00 is done when all local governance files exist, capability audit is written, checks run, GitHub status is PR or blocked, GPT Pro status is PASS or blocked, and phase gate result is PASS, FAIL, or BLOCKED.

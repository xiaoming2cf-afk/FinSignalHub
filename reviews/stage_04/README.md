# Stage 04 Review Artifacts

## Purpose

This directory contains review and acceptance artifacts for Stage 04 evidence extraction planning.

## Usage

- `GPT_PRO_REVIEW_PACKET.md` is the copy-ready packet for GPT Pro plan review.
- `PR_BODY.md` is the source for the GitHub PR body.
- `STAGE_ACCEPTANCE_RESULT.md` records the ten gate statuses.
- `CODEX_REVIEW_SUMMARY.md` records Codex findings and remediation status.
- `SUBAGENT_SUMMARY.md` records Stage 04 subagent usage and read-only audits.

## Boundaries

Stage 04 review artifacts may describe future extraction schemas, quote-span validation, no-quote rationale, provenance validation, mock LLM adapter plans, worker skeleton plans, and stop conditions. They must not implement extraction code, tests, fixtures, external LLM calls, claim graph logic, Research Delta logic, Repro Pack logic, MCP business tools, UI/dashboard behavior, chatbot/RAG behavior, stock prediction, investment advice, Risk Mode, or Replay Engine.

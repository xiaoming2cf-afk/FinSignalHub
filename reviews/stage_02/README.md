# Stage 02 Review Artifacts

## Purpose

This directory contains review and acceptance evidence for the Stage 02 Research Mode domain models plan. It is planning-only until GPT Pro plan review, current-head GitHub/Codex evidence, and user `/goal` approval authorize implementation.

## How future stages use this directory

- `GPT_PRO_REVIEW_PACKET.md` is the copy-ready packet for GPT Pro plan review.
- `PR_BODY.md` is the source for the Stage 02 pull request body.
- `CODEX_REVIEW_SUMMARY.md` tracks Codex review findings and remediation status.
- `SUBAGENT_SUMMARY.md` summarizes bounded read-only subagent verification.
- `STAGE_ACCEPTANCE_RESULT.md` records the ten gate results for Stage 02.

## Maintenance rules

Update these files whenever PR evidence, CI, Codex review, GPT Pro review, blockers, or gate status changes. Do not put implementation code, generated runtime output, secrets, or unrelated screenshots in this directory.

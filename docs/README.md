# Docs Directory

This directory stores FinSignalHub documentation that is not itself a control log. Product docs describe research workflow identity, architecture docs describe future technical boundaries, and Codex docs describe agent operating rules.

Stage 00 docs are governance-only. Stage 01 docs may describe the repo scaffold, health-only API surface, MCP server-info surface, inspect-only web admin shell, Docker Compose, and CI commands. Business API, database models, connectors, extraction, claim graph, Research Delta, MCP business tools, Repro Pack logic, chatbot UI, stock recommendation, investment advice, generic RAG, and dashboard product behavior must wait for the approved future stage that creates the corresponding surface.

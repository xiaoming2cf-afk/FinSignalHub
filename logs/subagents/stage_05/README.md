# Stage 05 Subagent Logs

This directory stores bounded Stage 05 planning subagent logs. Each log states the role, allowed and forbidden files, files touched, summary, risks, tests, and unresolved issues. Subagents for this planning stage may inspect and plan only; they must not create runtime claim graph, Research Delta, MCP business tool, Repro Pack, UI, chatbot, RAG, stock prediction, investment advice, Risk Mode, or Replay Engine files.

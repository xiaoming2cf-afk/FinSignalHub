# Stage 04 Deployment Artifacts

## Purpose

This directory records GitHub deployment evidence for Stage 04 evidence extraction planning.

## Usage

- `GITHUB_PR.md` records the active Stage 04 PR, branch, CI links, Codex review evidence, and GPT Pro handoff status.
- Future Stage 04 deployment files must remain planning or acceptance evidence until a separate Stage 04 implementation `/goal` is accepted.

## Boundaries

This directory must not contain application code, extraction implementation, provider credentials, generated evidence cards, claim graph outputs, Research Delta outputs, Repro Pack exports, or UI behavior.

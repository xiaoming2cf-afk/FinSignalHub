# 14 Demo Acceptance

## Purpose

Defines Stage 09 demo acceptance for the Research Mode MVP.

## Owner

Demo acceptance lead.

## When to update

Update when GPT Pro approves changes to demo scenarios or acceptance evidence.

## Required fields

- Demo name
- User need
- Required MCP calls
- Admin inspection evidence
- Repro pack output
- GPT Pro review material
- Pass condition

## Example format

`AI capability boundary scan | MCP call plus repro pack | pass when GPT Pro can inspect evidence`

## Current state

Stage 09 demos:

1. AI capability boundary scan.
2. Financial LLM temporal contamination research project.
3. FinSignalHub product design evidence pack.

Each demo must be callable through MCP tools, inspectable in admin UI, exportable as a Repro Pack, and reviewable by GPT Pro. Stage 09 cannot claim MVP completion without all three demos.

# CONTROL Directory

## Purpose

This directory is the source of truth for FinSignalHub governance, capability state, blocker tracking, stage gates, decisions, and review protocols.

## Owner

Codex log keeper and phase acceptance lead.

## When to update

Update directory guidance when a new control file is added, a governance rule changes, or GPT Pro changes the stage process.

## Required fields

- Directory purpose
- File naming convention
- Required control-file sections
- Update responsibility
- Current governance state

## Example format

`CONTROL/16_CAPABILITY_AUDIT.md | updated at stage start | owner: ai-capability-radar`

## Current state

Numbered control files `00` through `27` are present after Stage 00.1 RunLog setup. Each numbered control file must include Purpose, Owner, When to update, Required fields, Example format, and Current state. Future control records must follow the same structure.

# Computer Use Plugin Scripts

No executable script is provided in this plugin draft.

Computer Use cannot be safely emulated by blind keyboard or mouse scripts. Future scripts may be added only if an approved stage explicitly authorizes them and they can prove all of the following:

- They inspect page state before input.
- They avoid foreground interference while the user is active.
- They stop on login, MFA, captcha, permission, privacy, payment, subscription renewal, secret, or unclear consent prompts.
- They avoid saving or committing private browser context.
- They record exact evidence paths and gate status.
